Hamiltonian Playground

Type a Hamiltonian, watch it evolve, and see what a quantum computer's circuit would do.

Syntax
  • 0.5*Z0 Z1 Pauli operators on numbered qubits, multiplied together
  • ZZI - 0.3*XIX full Pauli strings: character i acts on qubit i
  • 2 - Z0 constants shift the energy but not the dynamics
  • # text comments run to the end of the line

Qubit 0 is written first everywhere, in strings and in kets like |01⟩. Qiskit uses the opposite order.

One character per qubit, qubit 0 first: 0, 1, + or -.

Any Pauli sum, or H for the energy.

More steps make the circuit more accurate but deeper. On real hardware every extra CNOT adds noise.

t = 0.00

"Exact" evolves the full quantum state with a series expansion accurate to machine precision. "Trotter circuit" is the noiseless product-formula circuit a quantum computer would run: the same answer, approximated in discrete steps. Up to 10 qubits.
